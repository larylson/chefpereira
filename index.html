🔄 Sincronização entre Dispositivos

O sistema sincroniza automaticamente pelo Firebase (projeto chef-pereira-gestao) entre todos os aparelhos onde você entrar com uma conta Google autorizada. Funciona também sem internet: o que for lançado offline é enviado quando a conexão voltar. Usuário atual: -.

Para autorizar outro usuário, adicione o e-mail dele nas regras de segurança do Firestore, no console do Firebase.

🌙 Aparência

Vale só para este aparelho.

Automático segue o celular/computador: escurece quando o aparelho está no modo escuro.

📲 App no celular e no computador

Instale o Chef Pereira como aplicativo: ganha ícone na tela inicial, abre em tela cheia e funciona sem internet (o que for lançado offline é enviado quando a conexão voltar).

  • Android (Chrome): toque no botão acima ou no menu ⋮ → Instalar app / Adicionar à tela inicial.
  • iPhone (Safari): toque em Compartilhar (□↑) → Adicionar à Tela de Início.
  • Computador (Chrome/Edge): ícone de instalar na barra de endereço ou o botão acima.

💾 Backup

Baixe uma cópia de tudo para guardar no celular, computador ou Google Drive. O ideal é fazer pelo menos uma vez por semana.

Último backup: nunca

O .json serve para restaurar o sistema. A planilha é para consultar no Excel/Google Planilhas (pedidos, itens, clientes, produtos, receitas, ingredientes, saídas). Antes de restaurar ou limpar, o sistema baixa sozinho uma cópia de segurança do estado atual.
